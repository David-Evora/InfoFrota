    01O problema
    
        
    Dados de transporte existem aos montes. Entendê-los é a parte difícil.
    
      
    

      
    
        
      
          
    1. 
            01
            
      Registros soltos
      
            
      Ocupação, linhas, paradas, horários e clima vivem em tabelas diferentes. Cada pergunta vira uma consulta escrita à mão, por quem conhece o esquema.
      
          
      2. 
          
    2. 
            02
            
      Contexto recuperado
      
            
      O InfoFrota busca só o que importa para a pergunta — tabelas, valores válidos e regras do domínio — para o modelo não adivinhar nomes de colunas.
      
          
      3. 
          
    3. 
            03
            
      Informação acionável
      
            
      A pergunta em português vira uma consulta validada, somente leitura. O resultado volta como tabela, resumo ou alerta que alguém pode usar.
      
          
      4. 
        
    

        
      
    

      
    
        
    O que é
    Um projeto independente que reúne dados de ocupação, frota, linhas e clima para apoiar o planejamento do transporte coletivo na Grande Vitória.
    
        
    Que problema ataca
    A informação existe, mas está espalhada e exige conhecimento técnico para ser consultada e comparada.
    
        
    Por que dados importam
    Picos de demanda, linhas sobrecarregadas e efeitos de calendário e clima só aparecem quando a informação é consolidada.
    
        
    Como a tecnologia ajuda
    RAG, modelos de linguagem e automação transformam uma pergunta em resultado verificável e um evento em aviso.
    
      
    
      
    O InfoFrota não é um sistema oficial da CETURB/ES nem possui endosso institucional. Hoje opera apenas sobre uma base experimental com dados sintéticos.

    03Inteligência artificial
    
        
    Não é só um chatbot. É um assistente que mostra o caminho.
    
        
    Cada resposta passa por recuperação de contexto, geração de SQL e validação antes de tocar nos dados — e o caminho inteiro fica visível.
    
      
    

      
    
        
    
          
    
          
        
    
        
    
          
    
          
      
        
      
        
      
          
          
          
        
      
        
      
          
          
      
        
      
      
      

      
      
        
      Contexto antes da geração
      Um índice BM25 recupera tabelas, valores válidos e regras do domínio e os coloca no prompt.
      
        
      Somente leitura, em três camadas
      Instrução única SELECT/WITH, authorizer do SQLite e conexão mode=ro, com limite de linhas e de tempo.
      
        
      Resposta rastreável
      O SQL gerado acompanha o resultado. Se a consulta falha, o modelo recebe o erro e tenta corrigir uma vez.
      
      
      

      
      
        
      
          
      Avaliação experimental
      Benchmark congelado de 56 perguntas

        05Alertas e automação
        
        
        Do dado ao aviso, a cada cinco minutos.
        
        
        O workflow n8n do repositório consulta a API, descarta o que já foi enviado e notifica um webhook do Discord ou do Slack.
        
      
        

      
        
        
        
          Workflow n8n/alerta-critico.json
          
        
        
        
          
        
          
      
          

      
          
        
          
          
          
            ATENÇÃO
            
          75% a menos de 90%
          
            
          Gerado e registrado na base. Não dispara notificação no workflow atual.
          
          
          
          
          
            CRÍTICO
            
          90% ou mais
          
            
          Entra na consulta do n8n e vira mensagem no webhook, uma vez por ID de alerta.
          
          
          
          
          
            RESOLVIDO
            
          Estado do alerta
          
            
          Cada alerta guarda se foi resolvido e se uma ação de precaução foi acionada.
          
          
          
        
          
        
      
          
      
          A deduplicação grava os IDs no armazenamento do próprio workflow e só depois que o envio é confirmado. O fluxo foi testado manualmente pelo autor com a API rodando e o workflow ativo; não há teste automatizado dele.

            08Sobre o projeto
            
        
            Informação de frota ao alcance de quem decide.
            
        
            O InfoFrota nasceu para facilitar o acesso a informações de ocupação e frota do transporte coletivo. A direção é usar processamento inteligente para responder perguntas, apontar situações de atenção e apoiar o planejamento — sempre dizendo com clareza o que é dado real e o que não é.
            
      
            
      
            
        
            Implementado
              
          
            • Assistente Text-to-SQL com RAG de esquema
            • API FastAPI com quatro rotas
            • Guarda de SQL somente leitura
            • Docker Compose com API e n8n
            • Workflow n8n de alerta crítico
            • Interface web de protótipo
            
        
            Experimental
              
          
            • Fine-tuning LoRA do Llama 3.1 8B
            • Benchmark de 56 perguntas
            • Base SQLite com dados sintéticos
            • Persistência da deduplicação no n8n
            
        
            Em estudo
              
          
            • Captação embarcada de passageiros
            • Conectividade embarcada e sincronização offline
            • Integração com dados operacionais autorizados
            • Autenticação e hardening para produção

            Rodar localmente
            
    
            Protótipo e este site
            
    
            Requer Python 3.11+. O modelo de linguagem só é necessário para perguntas ao vivo; sem ele, tudo o mais funciona.
            
    
            
      

            git clone https://github.com/David-Evora/InfoFrota.git
cd InfoFrota
pip install -r requirements-api.txt
python scripts/generate_data.py
python -m infofrota_ai.api
# site e assistente:  http://127.0.0.1:8000/
            
    
            
    
            Ou só o site, sem API: python -m http.server -d docs/site 8080 e abra localhost:8080/. Fora da API, a demonstração do assistente fica em modo simulado.

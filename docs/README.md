# Demonstração web do InfoFrota

Esta pasta é publicada pelo GitHub Pages quando a origem for configurada como branch `main`, pasta `/docs`.

A demonstração é um frontend estático com dados fictícios. Não possui backend, autenticação, integração com sensores, acesso à CETURB/ES nem execução real de SQL. A seção Assistente IA mostra respostas e SQLs ilustrativos; o módulo Text-to-SQL funcional está documentado separadamente e opera atualmente pela CLI em Python.
